# LoveTV 小电视 · 使用指南

> 这是一份给使用者看的简单说明，不需要懂编程。遇到问题先看「常见问题」。

## 这是什么

LoveTV 是一台 2.4 英寸彩色小屏幕桌面小电视，主要功能：

- 显示时间、日期、天气和温湿度
- 纪念日倒计时 + 情话动画
- 和另一台设备互发「想你」消息
- 两台设备之间实时语音对讲（半双工，像对讲机）

## 第一次使用：配网

1. 用 USB 给设备供电，等待开机。
2. 用手机或电脑连接 WiFi 热点 **`小电视`**（没有密码）。
3. 浏览器打开 **http://192.168.4.1**
4. 在网页上填写：
   - WiFi 名称和密码（家里的网络）
   - 城市名称
   - 纪念日（年 / 月 / 日）
   - 底部文字（可留空）
   - 本机 ID 和对方 ID
5. 点保存，设备会自动重启并联网。

如果你们有**两台设备**，请这样填：

| 设备 | 本机 ID | 对方 ID |
|---|---|---|
| 设备 1 | A | B |
| 设备 2 | B | A |

> 服务器地址已经内置，不需要填写。

配网成功后，屏幕会显示时间、天气和 IP 地址。

## 日常按键

| 按键 | 操作 | 功能 |
|---|---|---|
| VOL+ | 单击 | 主页：发送「想你」消息；纪念日页：返回主页；消息页：确认/退出；语音页：退出 |
| VOL+ | 双击 | 主页 ⇄ 纪念日页 |
| VOL+ | 长按 | 语音播放音量 +10 |
| VOL- | 单击 | 进入语音页并开始录音；录音中再按一次：停止并发送 |
| VOL- | 双击 | 调整屏幕亮度（60 → 100 → 30 循环） |
| VOL- | 长按 | 语音播放音量 -10 |
| BOOT | — | 已停用，没有任何功能 |

提示：

- 长按约 0.6 秒才会触发长按。
- 长按之后 0.5 秒内的单击会被忽略，属于正常防误触。
- 默认背光亮度 60%，默认语音音量 40%；手动调整后会记住，下次开机仍保持。

## 消息互动

1. 在**主页**单击 VOL+，屏幕会显示「已发送：芜湖！」。
2. 对方设备收到后会显示「对方喊你：芜湖！」。
3. 对方单击 VOL+ 回复，发送方会看到「对方已收到」——无论发送方当时在哪个页面，都会弹出提示，1 秒后自动关闭。

> 回复方显示「已回复：起飞！」1 秒后自动回到主页。

> 只有主页单击 VOL+ 才会发消息；在纪念日页单击 VOL+ 只是返回主页。

## 语音对讲

语音是**半双工对讲机模式**：一个人说话的时候，另一边听到的是之前收到的语音。

1. 单击 VOL-，进入语音页并开始录音，屏幕显示「正在录音，请说话…」。
2. 说完话，再单击一次 VOL-，停止录音并发送。
3. 对方收到后会自动播放。

规则：

- 一段录音最长 60 秒，到时间会自动停止并发送。
- 录音不足 1 秒会被丢弃，并提示「说话时间太短」。
- 录音期间收到的对方语音会丢弃，这是半双工的正常行为。
- 语音页中间始终显示小喇叭（空闲/录音/播放都显示）；语音通道未连接或发送失败时显示叉。
- 想退出语音页，单击 VOL+。

## 日常提示

- 屏幕常亮，没有休眠功能，一直插电使用即可。
- 右上角电池图标会显示电量，充电时显示满电。
- WiFi 断开时屏幕会提示一次「wifi unconnected」；单击 VOL+ 可以回到主页继续看时间。
- 语音卡顿时，尽量靠近路由器，WiFi 信号弱会影响通话。

## 常见问题

**屏幕不亮 / 黑屏**

先断电重新上电（设备没有复位键）。如果仍然黑屏，联系制作者。

**连不上 WiFi**

检查密码是否正确、WiFi 是不是 2.4GHz。配网页面保存后需要等设备自动重启。

**想换一个 WiFi / 重新配网**

设备已经保存过配置后，不会自动进入配网页面。需要重新烧录整片固件（会清空配置）或联系制作者处理。

**收不到对方消息 / 语音**

确认两台设备的「本机 ID / 对方 ID」是配对填写（A↔B），并且两台设备都在线。

**屏幕时间不对**

设备联网后会自动同步时间，请确认 WiFi 已连接。

## 附录：重新烧录固件（可选）

如果制作者给了你固件文件 `lovetv-direct-merged.bin`，可以自己烧录：

1. 电脑安装 **Flash Download Tool**（乐鑫官方工具）。
2. 用 USB 线连接设备，设备管理器里确认串口（常见 COM6）。
3. 打开工具，芯片选 **ESP32-S3**，模式选 **Develop**，加载方式选 **USB**。
4. 选择固件 `lovetv-direct-merged.bin`，地址填 **0x0**。
5. SPI SPEED 选 **80MHz**，SPI MODE 选 **DIO**，FLASH SIZE 选 **16MB**。
6. 点 START，等待 FINISH，然后**断电重新上电**。

> 整片烧录会清空已保存的 WiFi 配置，开机后需要重新配网。
