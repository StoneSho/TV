# lovetv-direct 烧录说明

## 一、环境

- PlatformIO（本机路径 `D:\anaconda3\Scripts\pio.exe`）
- 板子：星智 1.54TFT WiFi 版（ESP32-S3 N16R8，16MB Flash / 8MB PSRAM）
- 原生 USB 串口（USB CDC），常见 COM6；无 RST 键，烧录后断电重启

## 二、编译与烧录

```powershell
cd D:\VibeCoding\TV\lovetv-direct
pio run                        # 编译（当前固件约 2.33MB，ota_0 分区 6MB）
pio run -t upload --upload-port COM6  # 烧录正确启动链 + App，保留 NVS 配网
pio device monitor -p COM6 -b 115200
```

如果 USB 口显示为其他 COM 号，把 `-p COM6` 换成实际端口。

## 二之二、合并固件烧录（首次整片烧录或救援使用）

通用 `esp32-s3-devkitc-1` 板定义会生成 8MB bootloader，导致本板启动死循环（串口反复打印
`entry 0x403c98d0`）。工程现已使用星智 N16R8 自定义板定义，并在 PlatformIO 上传时自动改用
**已验证的小智 16MB bootloader + 分区表**。也可以手动烧录合并固件：

| 文件 | 说明 |
|---|---|
| `flash\lovetv-direct-merged.bin` | 小智 bootloader/分区表 + 本工程 App（DIO/80MHz/16MB），从 0x0 整片烧录 |

SHA256：`E6B37CD06F318750CA1912BBF07ECA4ED5304F5D4C746753C6D279B6980D6471`

烧录步骤（与之前小智固件完全相同）：

1. 运行 Flash Download Tool：芯片选 **ESP32-S3**，模式选 **Develop**，加载模式选 **USB**
2. 选择 `flash\lovetv-direct-merged.bin`，地址 `0x0`，勾选该行
3. 选对 COM 口；SPI SPEED 选 **80MHz**，SPI MODE 选 **DIO**，FLASH SIZE 选 **16MB**
4. 点 START，等待 FINISH
5. 烧完**断电重新上电**（无 RST 键）

> 整片烧录会清空 NVS，开机后需重新配网（热点 `小电视`，浏览器访问 192.168.4.1）。

## 三、首次使用

开机进入 AP 配网：

- 连接热点 `小电视`
- 浏览器打开 `http://192.168.4.1`
- 填 WiFi/城市/纪念日/底部文字/本机 ID/对方 ID，保存后自动重启

配网页新增字段说明：

| 字段 | 说明 |
|---|---|
| 城市名称 | 中文城市名，自动匹配城市代码（默认烟台 101120501） |
| 纪念日 年/月/日 | 相识纪念日（默认 2019/9/1） |
| 相识页底部文字 | 可留空，默认 `known since 2019.9.1` |
| 本机 ID / 对方 ID | 消息互通身份（默认 A / B），两台设备分别填 |

MQTT `117.72.44.85:1883` 和语音 `117.72.44.85:9002` 已固定在固件中，配网页不再提供修改字段。

## 四、按键操作

| 操作 | 功能 |
|---|---|
| VOL+ 单击 | 仅主页发送“芜湖”；纪念日页返回主页；消息页回复/确认/退出；语音页退出并回主界面 |
| VOL+ 双击 | 主界面 ⇄ 纪念日页 |
| VOL+ 长按 | 音量 +10 |
| VOL- 单击 | 普通页进入语音页并开始录音；录音中停止并发送 |
| VOL- 双击 | 亮度 60→100→30 循环 |
| VOL- 长按 | 音量 -10 |

语音默认播放音量为 40%，调整后记忆。
默认背光亮度为 60%，调整后记忆。

> BOOT 键已停用，无任何功能；纪念日页切换使用 VOL+ 双击。

## 四之二、串口调试命令

打开串口监视器（115200，发送行尾选“换行”）后可直接输入命令，用来区分软件和硬件问题：

| 命令 | 作用 |
|---|---|
| `boot_short` | 模拟 BOOT 单击，应切换到纪念日页/返回主界面 |
| `boot_long` | 模拟 BOOT 长按，应切换背光亮度 |
| `boot_level` | 读取一次 GPIO0 电平（不按应为 HIGH） |
| `boot_test` | 5 秒内按/放 BOOT 三次，统计电平变化与最终电平 |
| `help` | 列出命令 |

## 五、恢复出厂小智固件

如需回滚到原厂小智固件：

1. 备份当前固件：`python -m esptool --chip esp32s3 -p COM6 read_flash 0 0x1000000 backup.bin`
2. 使用 Flash Download Tool 或 esptool 把
   `D:\VibeCoding\TV\lovetv-xiaozhi\flash\factory-merged.bin` 烧到 `0x0`
3. 整片烧录会清空 NVS，恢复后需重新配网

> PlatformIO 上传会刷新 bootloader、分区表、OTA 初始数据和 `0x100000` App，但保留 NVS；
> 手动烧录合并固件会清空 NVS。两种方式都不影响用出厂镜像回滚。

## 六、常见问题

- **串口反复出现 `entry 0x403c98d0`**：仍在运行旧的 8MB bootloader。请重新执行
  `pio run -t upload --upload-port COM6`，看到成功后断电重新上电。正常的新 bootloader 入口为 `0x403c88f4`。
- **语音断连/不流畅**：设备 WiFi 信号较弱（RSSI -77~-85），尽量靠近路由器；
  固件已关闭 WiFi 省电并 2s 快速重连。
- **WiFi 断开提示**：断网只显示一次“wifi unconnected”，返回主页后不会再被强制跳页；重新联网后恢复。
- **语音延迟**：已优化为 180ms 预缓冲 + 24 帧发送队列/16 帧播放队列（满时丢旧保新）；录音/播放期间跳过天气刷新，避免阻塞语音。
- **录音太短**：不足 1 秒的录音会丢弃并提示“说话时间太短”。
- **语音被丢弃**：半双工设计，录音时收到的远端语音帧会丢弃。
- **屏幕颜色/方向不对**：可在 `setup()` 中调整 `tft.invertDisplay()` 与
  `tft.setRotation()`；星智屏默认 invert=1、rotation=0。
