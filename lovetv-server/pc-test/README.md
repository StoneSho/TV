# LoveTV PC 测试台

浏览器页面，用于单台单片机联调：

- MQTT：通过 `ws://117.72.44.85:9001/mqtt` 收发 `imu/check/自定义` 文字消息
- 语音：通过 `ws://117.72.44.85:9002/voice` 按住说话（IMA ADPCM 16kHz/30ms，与单片机一致），并实时解码播放单片机发来的语音

## 启动

```bash
start_pc_test.bat
```

然后浏览器打开 `http://localhost:8000`。

## 使用

1. 设备 ID = 单片机配置页里的“本机 ID”（默认 A）；本机 ID = 单片机配置页里的“对方 ID”（默认 B）。
2. 点“连接全部”，两个状态变绿。
3. 文字：选类型 → 发送；单片机 VOL+ 单击发来的消息会显示在日志。
4. 语音：按住“按住说话”讲话，单片机自动播放；单片机 VOL- 短按讲话，这里会实时播放。

## 文件

- `index.html` / `app.js`：页面与逻辑
- `mqtt.min.js`：MQTT.js
- 语音编解码为纯 JS 实现的 IMA ADPCM（4bit），无 WASM、无外网依赖
